## 五、保姆级使用/交付 SOP 与私藏技巧

### 早晚SOP
**早上：**
1. 精粹水按压两遍，轻拍上脸，第一遍唤醒，第二遍补水。  
2. 1泵水光精华，从下往上轻拍全脸，重点按压法令纹。  
3. 薄涂面霜锁水，掌心搓热后按压。  
4. 防晒！防晒！防晒！  

**晚上：**
1. 精粹水湿敷打底，重点敷两颊和法令纹3-5分钟。  
2. 2泵水光精华，用指腹在法令纹、下颌线做提拉按摩。  
3. 眼霜取绿豆大小，无名指点涂眼周，逆着纹路轻轻按摩至吸收。  
4. 取珍珠粒大小面霜，掌心乳化后按压全脸，不要搓。  

### 主理人私藏小技巧
> 把精粹水装进小喷壶，上妆前喷湿美妆蛋，粉底会像长在脸上一样服帖；晚上湿敷时，用化妆棉剪成小条，专门敷在法令纹和眼尾，效果翻倍。
