## 🎨 PPT 整体设计系统与视觉风格指南 (Visual Design System & Presentation Style)

为了确保本次内部汇报能够精准传达**“企业级数字化中枢的严谨科技感”**与**“健康服务伴随式顾问的温暖人情味”**，全套 PPT 需严格遵循以下设计规范：

### 1. 核心设计基调 (Design Tone & Persona)
* **主基调**：**克制、严谨、现代、具陪伴感**（Professional, Reliable, Modern, Empathetic）。
* **设计原则**：
  * **拒绝花哨**：摒弃纯互联网概念炒作的浮夸霓虹渐变与杂乱元素，采用**极简留白、大字焦点与结构化卡片（Bento Grid）**；
  * **科技与健康的平衡**：以严谨的深色/科技蓝作为企业架构底色，以柔和的健康翡翠绿与温润白承载客户服务体验；
  * **场景化还原**：重度使用真实的**微信对话气泡图、H5 手机交互模型、结构化 Markdown 档案卡片**，让管理层直观感受 C 端客户体感。

### 2. 色彩系统规范 (Color Palette)

| 色彩角色 | 色值 / 示例 | 语义与应用场景 |
|:---|:---|:---|
| **主色 (Primary)** | **科技深海蓝** (`#0F172A` / `#1E3A8A`) | 用于封面背景、大标题、系统架构框图、企业级安全底座 |
| **辅色 (Secondary)** | **健康翡翠绿** (`#0D9488` / `#10B981`) | 用于健康档案徽章、正向业务指标、在线运行状态、医疗健康元素 |
| **交互色 (Accent)** | **活力琥珀橙** (`#F59E0B` / `#EA580C`) | 用于痛点警示、核心抓手、重点数据大字、工单流转节点高亮 |
| **中性色 (Neutral)** | **高雅云雾白 / 浅灰** (`#F8FAFC` / `#FFFFFF`) | 用于内页背景底色、内容承载卡片底色（轻微 1px 细边框 `#E2E8F0`） |
| **文字色 (Text)** | **碳素黑** (`#1E293B`) / **次级灰** (`#64748B`) | 保证在投影仪或屏幕共享下具备极高对比度与清晰可读性 |

### 3. 版式结构与排版法则 (Layout & Typography)
* **字阶体系 (Typography)**：
  * **Slide 主标题**：`28 ~ 32 pt` 粗体（一目了然的结论式标题，如：“*架构全景：感知 ➔ 认知 ➔ 调度的三层业务闭环*”）；
  * **核心观点 (Takeaway 导语)**：`16 ~ 18 pt` 中粗体，放置在标题正下方，1 句话总结本页核心决策价值；
  * **正文/列表**：`13 ~ 15 pt`，行距 1.4 倍，控制单行字数，禁止出现大段密集排版；
  * **关键数字/指标**：`40 ~ 54 pt` 极粗大字（如：`99.9%`、`< 2s`、`100%`），搭配下方小字说明，形成强烈视觉抓手。
* **容器化卡片布局 (Containerized / Bento Grid)**：
  * 内页采用 **2 列（对比/双轮驱动）** 或 **3~4 列（矩阵/步骤/场景）** 的圆角卡片（`border-radius: 12px`）；
  * 每张卡片聚焦一个子论点，左上角搭配清晰的业务图标（Icon）。

### 4. 图表与视觉元素规范 (Visual Asset Guidelines)
* **架构图 (Architecture Diagrams)**：采用自下而上的立体层次，使用不同颜色色块清晰区分“感知接入”、“活体记忆”、“Agent 调度”三大系统边界；
* **场景还原 (Mobile Mockups)**：在展示“日常轻问答”和“H5 体检工单”时，使用真实的 iPhone 手机模型框架，还原微信气泡与 H5 网页；
* **流程与时间轴 (Timeline & Process)**：横向步骤流转图（Step 1 ➔ Step 2 ➔ Step 3 ➔ Step 4），箭头使用虚线与动效光点表示异步与回调。

### 5. 演讲与汇报节奏把控 (Presentation Rhythm)
* **前 3 分钟（P1-P3）**：直奔主题，讲透 B2B2C 定位，解答“我们在做什么、为什么不是个人玩具”；
* **中段 8 分钟（P4-P13）**：重锤敲击“数据基座 ➔ Agent 核心能力 ➔ 3 大实战场景 ➔ 4 大配置扩展机制”，展现系统的落地可行性与工程壁垒；
* **收尾 4 分钟（P14-P15）**：用量化成效与“四大数字化员工特种军团”引发管理层共鸣，展望公司全业务赋能蓝图。

## Slide 4: 核心支撑 1 — 多模态感知网络与跨渠道身份归一
* **核心观点 (Takeaway)**：无论客户在哪个渠道以何种形式表达，系统秒级理解且数据资产全局归一。
* **独家亮点与落地机制**：
  1. **全媒体格式无感解析网络**：
     * 📝 **文字与表情**：即时语义提取与情绪感知；
     * 🎙️ **语音消息**：自适应双引擎 STT（火山大模型 ASR 首选 + Gemini 备用），方言与口语转写准确率 >98%；
     * 📸 **医学图片与生活照**：Gemini Vision 毫秒级视像解析（精准识别药盒成分、化验单数值、早餐菜品）；
     * 📑 **体检单与 PDF 报告**：智能文本层提取 + 视觉 OCR 双重保障，结构化抽取异常指标与参考区间。
  2. **跨渠道统一身份中枢 (Unified Identity Engine)**：
     * 依托微信 UnionID 机制，自动将客户的“个人微信会话、企业微信联系人、第三方渠道会话”自动合并为单一全局主账号；
     * 历史咨询记录、体检报告、过敏史及用药计划自动合并归一，彻底消除“多重账号信息分散”。
* **视觉建议**：左侧为多格式输入图标汇总，右侧为个人微信/企微会话合并至唯一“数字健康卡”的漏斗图。

## Slide 5: Agent 核心技术基座（精炼解析）
* **核心观点 (Takeaway)**：高内聚的闭环执行引擎，平衡响应速度、专业深度与计算成本。
* **四大独家技术基座支柱**：
  1. **Agent Loop 协同闭环**：感知 ➔ 意图路由 ➔ 决策（直接回复 vs 专家沙箱）➔ 执行 ➔ 观察反思 ➔ 拟人交付。
  2. **轻重双轨分流 (Fast/Slow Routing)**：
     * 🟢 **快轨（日常轻问答）**：带入病史秒级直答（<2秒响应，无需启动沙箱）；
     * 🔵 **慢轨（专家级深度分析）**：自动拉起独立安全沙箱，执行复杂 Python/数据分析模型。
  3. **上下文压缩与 Token 经济学 (Token Economics)**：
     * 拒绝无脑拼接数万字历史记录；采用“静态用户画像 + 精准 Prefetch 召回片段”组合；
     * **Token 消耗降低 70%~80%**，同时消除因上下文过长导致的大模型注意力稀释与幻觉。
  4. **守卫确认机制 (Guard Pattern)**：
     * 涉及深度报告解读等重服务前，主动探寻客户意图并生成确认链接，防止 Agent 越俎代庖盲目开工单。
* **视觉建议**：紧凑的环形 Agent Loop 架构示意图，包含分流、压缩、沙箱与守卫四大组件。

## Slide 6: 核心支撑 2 — LLMWiki 活体健康记忆系统
* **核心观点 (Takeaway)**：拒绝黑盒幻觉，用“8 大认知骨架”与“点击即溯源”打造可信档案。
* **独家架构设计亮点**：
  * **8 大标准健康认知骨架**：涵盖《当前主要关注》、《事件时间轴》、《生理信号》、《化验结果》、《功能变化》、《干预措施》、《监测目标》、《原始证据》。
  * **动态自演进 Markdown 百科**：无需人工整理，后台 LLM 自动将碎片对话萃取并增量编织进对应篇章，形成结构清晰的活体病历。
  * **100% 原始证据链溯源 (`[🔗 溯源]`)**：
     * 每一个身体特征、过敏史均标注来源日志 ID（如 `[🔗 溯源](log_1786...)`）；
     * 顾问或质检员点击即可一键穿透查看当时的原始微信对话或化验单原图，经得起专业核验。
  * **零延迟极速召回 (Prefetch)**：双分词与标题加权内存检索，无需昂贵向量计算，0 毫秒将最相关病史注入当前对话。
* **视觉建议**：右侧展示结构化 Markdown 百科界面，高亮 8 大板块与可点击的“溯源徽章”。

## Slide 7: 应用场景 1 — 日常伴随式轻问诊与慢病随访
* **核心观点 (Takeaway)**：在细微处体现专业，像真人一样有记忆、有呼吸感地陪伴。
* **独家体验亮点（真实案例还原）**：
  * **饮食多模态静默感知**：客户早晨发来一张早餐香肠照片，视觉引擎瞬间捕获“盘中有煎香肠与鸡蛋”，静默存入附件库不打扰用户；
  * **跨轮次记忆排查**：客户随后问“身体有点痒，早饭吃这个有关系吗？”，Agent 瞬间调取【血压用药档案】与【刚刚暂存的香肠图片】；
  * **1.5 秒呼吸感拟人分段下发 (Paced Dispatcher)**：
    * 拒绝单次 400 字小作文轰炸，后置格式化引擎将长回复切为 2~3 个自然短句：
    * 💬 *消息 1（秒级安抚）*：“oscar，查了档案您目前没服药，排除药物因素，先放宽心～”
    * *(停顿 1.5 秒模拟真人打字)*
    * 💬 *消息 2（专业建议与互动）*：“香肠属于加工肉，组胺较高确实可能诱发皮肤瘙痒。您今天早餐还配了海鲜或坚果吗？”
* **视觉建议**：微信双气泡模拟界面，展示照片识别标签与带时间间隔的消息依次弹出动态效果。

## Slide 8: 应用场景 2 — 深度医学报告解读（工单化闭环）
* **核心观点 (Takeaway)**：将晦涩难懂的医疗体检单，转化为客户易读、结构严谨的行动指南。
* **业务流程与体验创新**：
  1. **自动识别与挂载**：客户微信发送《影像报告.pdf》，系统后台自动完成文本抽取与 OCR 预解析；
  2. **专属 H5 极速确认**：客户说“帮我看看”，Agent 自动生成带预填信息的专属 H5 链接，用户一键确认；
  3. **专家 Agent 沙箱深度计算**：用户确认后，后台拉起《医学报告解读助手（MD版）》沙箱，逐项指标比对参考范围、分析潜在健康风险；
  4. **交互式报告呈现与通知**：自动生成排版精美、带生活干预指导的专属报告网页，并通过微信实时通知用户查阅。
* **视觉建议**：从 PDF ➔ H5 确认页 ➔ 最终精美体检解读网页的流程截图。

## Slide 9: 应用场景 3 — 主动健康方案督导与持续跟进
* **核心观点 (Takeaway)**：告别“问一次答一次”的被动交互，转变为基于健康目标的连续随访。
* **核心业务能力**：
  * **健康目标动态绑定**：根据客户健康百科中的《当前干预措施》（如每周 3 次抗阻运动、低盐控压饮食）；
  * **个性化督导互动**：当客户询问用药或运动时，Agent 自动根据其血压历史调整建议（如“给肌肉留恢复期，不建议每天高强度连练”）；
  * **长周期主动触达**：结合定时任务引擎，在关键节点提醒测血压、记录身体反应，形成连续健康追踪曲线，提升客户粘性。
* **视觉建议**：客户每周血压/运动目标打卡与 Agent 互动记录的趋势时间轴。

## Slide 10: 平台配置化能力 — Agent Profile 灵活定制中心
* **核心观点 (Takeaway)**：业务人员无需懂代码，即可在后台像“搭积木”一样定义数字顾问。
* **四大配置化维度与业务价值**：
  1. **人设与角色定位 (Role & Persona)**：自由配置顾问姓名、专业头衔（如慢病管理师、高级营养顾问）、角色描述与职责边界；
  2. **回复风格与字数控制 (Reply Style)**：自定义亲切度、专业严谨度、段落拆分偏好及单条字数上限（如 60~100 字短句优先）；
  3. **合规红线与禁忌词库 (Taboos)**：统一配置业务禁忌与禁止出现的词汇（如严禁确诊、严禁推销特定处方药）；
  4. **知识库与工具动态装配 (Knowledge & Tools)**：一键绑定对应的健康百科模块、工单查询工具或外部知识库，实现“一人一脑”。

## Slide 11: 平台扩展性 — 插件化 Skill 敏捷定义与沙箱隔离
* **核心观点 (Takeaway)**：企业新业务、新健康管理能力可在数小时内以 Skill 插件形态快速上线。

* **企业级安全沙箱 (Sandbox Isolation)**：所有复杂 Skill 运行在隔离的容器沙箱中，环境独立、互不干扰、保障核心系统安全与稳定性。
